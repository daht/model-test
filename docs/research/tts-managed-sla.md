# 托管 TTS 并发与实时指标调研

**调研日期：** 2026-07-26  
**范围：** 火山引擎（豆包语音）与腾讯云 TTS 的官方公开资料。  
**说明：** 本文只把厂商文档明确写出的限制作为事实。首包延迟、chunk 间隔和 P95/P99 通常不是公开 SLA，不能用宣传页或单次体验替代；上线前应要求商务/工单提供地域、音色、接口版本和并发档位对应的书面承诺。

## 结论摘要

| 厂商 | 官方公开的流式能力 | 公开的统一并发/SLA 数值 | 生产前必须确认 |
|---|---|---|---|
| 火山引擎/豆包语音 | WebSocket 双向流式接口，支持增量音频返回 | 在公开接口文档中未找到跨账号、跨地域统一的 TTFA/chunk-gap P95 SLA；并发通常按账号/应用配额控制 | 单连接并发、QPS/新建连接速率、排队超时、首包 P95、音频块间隔 P95、突发策略和提额流程 |
| 腾讯云 TTS | 提供 WebSocket 流式合成接口；HTTP/SDK 接口另有调用限制 | 产品文档未给出可直接作为生产承诺的 TTFA/chunk-gap P95；请求频率/并发额度以控制台配额和账号实际开通值为准 | 长连接上限、并发连接数、QPS、单请求最大文本/时长、超限错误码、跨地域网络延迟和 SLA 赔付条款 |

因此，当前 CosyVoice3 的实测 `TTFA P95 ~0.59s`、`chunk gap P95 ~1.48s` 只能与托管服务做基准对比，不能声称低于或高于厂商 SLA。两家厂商都需要在目标地域和目标音色上做同语料压测。

## 火山引擎/豆包语音

### 官方资料

- 产品文档首页（语音合成/流式能力入口）：<https://docs.volcengine.com/docs/6561/1257543>
- 火山引擎 API 文档目录（产品 6561）：<https://www.volcengine.com/docs/6561>
- 火山引擎服务配额/限流以账号控制台和工单为准；文档未公布一个适用于所有账号和地域的 TTS 并发 SLA。

公开 WebSocket 协议描述了建立连接、发送文本和接收音频事件的流程，但没有给出“首包不超过 X ms”或“音频 chunk 间隔 P95 不超过 Y ms”的统一承诺。即使接口支持流式，也不能据此推导单卡或单账号的并发数。

### 需要向厂商确认的条目

1. WebSocket 长连接最大数量，以及每秒新建连接速率（区分账号、应用、地域）。
2. 同一连接内是否允许多段文本并行；一连接一请求还是可复用连接。
3. TTFA P50/P95/P99、后续音频块间隔 P95/P99、服务端排队时间的定义和统计窗口。
4. 超限时的错误码、重试建议、连接空闲超时和最大合成时长。
5. 目标音色/模型是否需要单独开通，提额是否需要商务审批。

## 腾讯云 TTS

### 官方资料

- TTS 产品文档首页：<https://cloud.tencent.com/document/product/1073>
- WebSocket 流式合成接口说明：<https://cloud.tencent.com/document/product/1073/37922>
- TTS API 参考（请求参数、错误码等）：<https://cloud.tencent.com/document/product/1073/37921>
- 腾讯云 API 频率/配额的通用说明：<https://cloud.tencent.com/document/product/598/32738>

腾讯云公开文档确认 WebSocket 流式合成和增量音频返回，但公开页面没有可直接引用的统一 TTFA 或 chunk-gap P95 SLA。并发、频率和资源配额需要以账号控制台“配额/限流”页面及实际地域开通值为准；通用 API 文档也说明不同产品的限制可能不同，超限通常返回限流错误。

### 需要向厂商确认的条目

1. WebSocket 并发连接上限、单账号 QPS 和突发（burst）额度。
2. 流式接口的首包、分片大小/间隔、服务端缓冲策略及指标定义。
3. 单次请求文本长度、最大音频时长、连接和请求超时。
4. 限流错误码及是否建议指数退避；提额的审核时间和上限。
5. SLA 的可用性百分比、故障统计口径、地域和专属线路条件。

## 建议的可比验证方法

厂商没有公开可比的延迟 SLA 时，使用同一套客户端、语料和指标分别压测：

- 并发阶梯：1、2、4、8、16（直到出现限流或 TTFA P95 越过目标）。
- 到达率阶梯：0.03、0.05、0.08、0.10 RPS，并记录实际接受率。
- 指标：成功率、限流率、TTFA P50/P95/P99、chunk gap P95/P99、断流时长、RTFx、音频连续性。
- 测试条件：固定地域、固定音色、固定文本长度和网络；分别记录冷启动与热运行。

建议把供应商书面回复（配额截图、工单号、SLA 附件）与压测报告一并归档。没有书面数字时，只能报告“接口支持流式，配额按账号开通”，不能把经验值当作 SLA。
